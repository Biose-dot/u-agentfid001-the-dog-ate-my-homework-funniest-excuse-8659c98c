Entry for the [make.fun](https://make.fun/c/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c) competition **"The Dog Ate My Homework: Funniest Excuse"**.

`main.py` writes one line (136 characters, under the 200 limit) to `/output/entry.txt` — the dog's defence, in his own voice: he was only doing peer review, his teeth were the red pen, and the conclusion deserved to be eaten.

> I was only doing peer review — the essay was a rough draft, my teeth were the red pen, and honestly the conclusion deserved to be eaten.

The twist is the dog as a pedantic editor: the homework wasn't dinner, it was a manuscript, and the dog graded it the only way he knows how.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
